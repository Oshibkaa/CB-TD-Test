## Navigation Tool Specification

## Проблема

Инструмент должен упростить и ускорить создание и настройку последовательных маршрутов на сцене без ручного создания и связывания каждой точки

Пользователь открывает окно инструмента, создаёт новый или выбирает существующий RouteController и добавляет RoutePoint. Новая точка автоматически создаётся из prefab и сразу добавляется в маршрут

Пользователь может:
- добавлять новые точки
- менять их порядок
- удалять точки
- выбирать точку из списка и быстро переходить к ней на сцене

Для удобства работы точки маршрута должны отображаться по понятным именам

Настраиваемые параметры:
- prefab RoutePoint
- prefab marker
- размер trigger-зоны
- порядок точек маршрута

Инструмент должен автоматически проверять:
- отсутствующие ссылки
- дубликаты точек
- отсутствие Collider
- выключенный Is Trigger
- отсутствие RoutePoint или marker

## Результат

Готовый настроенный маршрут, который можно быстро создать, изменить или расширить без ручной настройки каждой точки
